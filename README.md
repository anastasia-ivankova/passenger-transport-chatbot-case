# passenger-transport-chatbot-case
## "Чат-бот для автоматизации взаимодействия автотранспортной компании с клиентами" 
Проект разработан в рамках ВКР по направлению «Бизнес-информатика».

В основе проекта - анализ процесса оформления заказных пассажирских перевозок. До автоматизации клиентские обращения обрабатывались руководителем вручную: консультация, сбор данных, оформление заказа-наряда и отправка документов. Разработанный чат-бот переносит типовые операции в цифровой канал и позволяет клиенту самостоятельно получить информацию, оформить заказ, управлять профилем и просматривать историю заказов.

Система реализована на Python с использованием VK API, SQLite и Email. Для проектирования использованы BPMN 2.0, UML и IDEF1X. База данных хранит сведения о заказчиках и заказах, а после оформления заказа система автоматически формирует заказ-наряд и отправляет его клиенту по электронной почте.

Расчёт показал сокращение времени обработки заказа нового клиента с 51,5 до 20,5 минут, а постоянного клиента — с 34 до 11,5 минут. Потенциальная экономия рабочего времени составляет 4,9–6,7 часа в месяц, расчётный эффект от сокращения трудозатрат — 2 633,75–3 601,25 ₽ в месяц.
